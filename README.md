# ☕ Coffee Ordering System

A simple **Python console-based Coffee Ordering System** built using **Object-Oriented Programming (OOP)** concepts.

## 📌 Features

* Display available coffee menu
* Add coffee to the order
* Automatically increase quantity when the same coffee is selected
* View ordered items
* Calculate the total price
* Checkout and confirm the order
* Clear the order after successful checkout
* Handle invalid menu choices

## 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)

## 📚 Python Concepts Used

* Classes and Objects
* `__init__()` constructor
* Instance variables
* Methods
* Lists
* Dictionaries
* `for` and `while` loops
* `if-elif-else`
* `input()` and `print()`
* `enumerate()`
* `sum()` / calculations
* String formatting
* List/dictionary data handling

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd coffee-ordering-system
```

### 3. Run the Python program

```bash
python main.py
```

## 💻 Example

```text
--- Coffee Menu ---
1. Espresso - $2.5

3. Cappuccino - $3.0
4. Americano - $2.0
5. View Order

Choose an option: 2
```

If the same coffee is selected multiple times:

```text
Your Order:
```
